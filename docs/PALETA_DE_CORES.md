## Gradientes

- **Gradiente principal (folhas):** `#1B5E34` → `#8BC34A` (verde escuro para claro)
- **Gradiente de fundo sutil:** `#FFFFFF` → `#F5F5F5`

## Tipografia (referência do logo)

- **"INSTITUTO"** — Caixa alta, espaçamento largo, serifada
- **"DALTON SALOMÃO"** — Caixa alta, bold, serifada
- **"FUTURO SE FAZ COM AMOR"** — Caixa alta, itálico, espaçamento largo

## Aplicação no Sistema

- **Barra de navegação:** Verde Escuro (`#1B5E34`) com texto branco
- **Botão primário:** Verde Médio (`#2E7D42`) com texto branco
- **Botão primário (hover):** Verde Escuro (`#1B5E34`)
- **Botão secundário:** Borda Verde Médio, fundo branco, texto Verde Médio
- **Links:** Azul (`#1976D2`)
- **Fundo da página:** Branco (`#FFFFFF`)
- **Cards/painéis:** Fundo Cinza Claro (`#F5F5F5`), borda sutil
- **Mensagens de sucesso:** Verde Claro (`#8BC34A`)
- **Mensagens de erro:** Vermelho (`#D32F2F`)
- **Mensagens de aviso:** Amarelo (`#F9A825`)
- **Mensagens informativas:** Azul (`#1976D2`)
- **Sidebar/menu lateral:** Verde Escuro (`#1B5E34`) com itens em branco
- **Logo:** Sempre visível no topo esquerdo da navegação
